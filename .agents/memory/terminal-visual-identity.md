---
name: Terminal visual identity
description: The intended visual language for the Aztech institutional site.
---

The Aztech institutional pages use a dark terminal-inspired interface: black and deep green surfaces, restrained neon-green highlights, monospaced typography, technical borders, grid and scanline textures, and square-cornered panels. The Gazstao page remains the most explicitly Matrix-like expression of the same direction.

**Why:** The user requested a closer visual connection to Matrix and terminal interfaces across the whole site, not only the Gazstao profile.

**How to apply:** Preserve this visual language for additions to public pages. Prioritize readable contrast and restrained effects over dense animation or low-contrast neon text.
