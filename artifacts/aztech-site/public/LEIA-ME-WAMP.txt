AZTECH ALTA TECNOLOGIA — VERSÃO PRONTA PARA WAMP

1. Extraia este pacote diretamente em:

   C:\wamp64\www

   Este pacote foi compilado para a raiz do Apache. Ao final, confira
   se estes arquivos existem:

   C:\wamp64\www\index.html
   C:\wamp64\www\.htaccess
   C:\wamp64\www\assets\index-*.js
   C:\wamp64\www\assets\index-*.css

   Em algumas instalações, o caminho da pasta pública é:

   C:\wamp\www

2. Inicie o Apache pelo painel do WAMP.
3. Acesse:

   http://127.0.0.99/

   Também pode usar http://localhost/

O pacote já foi compilado com BASE_PATH=/ e já inclui o arquivo .htaccess
mínimo para as rotas do React. CSS e JavaScript usam os tipos MIME padrão
do Apache.

Se as páginas internas retornarem 404 ao atualizar o navegador, habilite
o módulo rewrite_module no Apache:

WAMP > Apache > Apache modules > rewrite_module

Depois reinicie o Apache.

Este pacote é estático. Não é necessário instalar Node.js, pnpm, PHP ou
MySQL para executá-lo no WAMP. O site atualmente não usa banco de dados.
